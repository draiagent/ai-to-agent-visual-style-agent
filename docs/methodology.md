# VSA 方法定義

VSA：Visual Style Agent，中文名稱「視覺設計代理」；既有圖卡亦使用「視覺風格 Agent」。VAC：Visual Agent Card，記錄可執行、可驗收、可交付的任務規格。

| 分工 | 責任 | 產物 |
|---|---|---|
| 使用者 | 提供需求、素材與設計確認 | 六項輸入、確認意見 |
| VAC | 明確定義任務與通過條件 | 工作規格 |
| 風格參考 | 指定應保留的視覺特徵 | 色彩、材質、排版規則 |
| Agent | 選擇可用工具、生成、檢查與修正 | 圖卡與問題紀錄 |
| 驗收 | 逐項比對規格與成品 | 通過／失敗／未驗證 |

沿用 RE:Agent 的「看、拆、定、找、組、驗」學習思路，不修改其原方法架構；本專案將之用於視覺任務。

先完成兩張並取得設計確認，再批次製作。遇到缺素材、權利不明或無法達成指定尺寸時，列出缺項，不虛構素材或將未通過標為通過。修正要指出頁碼、位置、替換文字與保持不變的部分。反覆修正仍失敗時停止該項並回報原因。
