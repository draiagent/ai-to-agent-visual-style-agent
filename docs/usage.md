# 使用方式

1. 整理內容重點，為每頁設定一個主要訊息。
2. 填寫設計尺寸：比例與實際像素分別指定，例 9:16、1080×1920。
3. 提供商標Logo原檔，註明右上位置與留白。
4. 選定參考風格，本系列使用極光玻璃；不要混合十五種風格。
5. 提供裝飾圖片，指定首頁人物、每頁玩偶與不可遮擋區域。
6. 填妥署名版權，列出素材來源及可使用範圍。
7. 附上 VAC 給具備圖像工具的 Agent。先確認前兩頁，後續沿用相同字級與面板規格。
8. 下載後核對實際像素、文字、Logo與頁碼，填寫驗收表；不以提示詞中的尺寸代替實際檢查。

可直接使用的指令：

> 請依附件 VAC 製作圖卡。先讀取六項輸入，缺項請列出。先完成兩頁確認設計，再製作其餘頁。保留主風格特徵，逐頁檢查文字、尺寸、Logo、署名、頁碼與遮擋。未通過先修正，無法完成則明確回報。
